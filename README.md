# PoS Card Maker plugin

Plugin portable para Codex y ChatGPT. Incluye la skill `pos-card-maker` y sus ocho referencias pictóricas (aprox. 4,5 MB).

## Instalar desde GitHub

En Codex, añade el marketplace:

```sh
codex plugin marketplace add nijuroku/pos-card-maker-plugin
```

Después instala **PoS Card Maker** desde el directorio de plugins. También puedes invocar la skill directamente con `$pos-card-maker`.

El repositorio debe permitir que el entorno que instala el plugin lea su contenido. Un repositorio público facilita el acceso desde otros entornos; uno privado requiere que estén autenticados con permiso de lectura.
